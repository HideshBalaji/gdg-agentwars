We don’t just ask the model not to hallucinate; we measure it. Groundedness: we extract every truck ID, rupee amount and time from an agent’s reply and check each one appears in the tool results from that same turn. Truthfulness: an agent may never say “booked” unless the execute tool returned a receipt, and offline output must be labelled simulated. Trajectory: for each of six scenarios — the rescue handover, a carrier quote and status check over A2A, an outage with fallback, learning from feedback, and PII redaction — we assert the expected handovers and tool calls. On the latest offline run all six pass: trajectory, groundedness and truthfulness are 1.00 in every scenario, with zero hallucinated replies. These are offline numbers from the deterministic model double; in live mode the same scenarios run against Gemini as ADK eval sets with an LLM-judge rubric. The suite runs in CI on every push.
