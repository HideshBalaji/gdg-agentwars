We don’t just ask the model not to hallucinate; we measure it. Groundedness: we extract every truck ID, rupee amount and time from an agent’s reply and check each one appears in the tool results from that same turn. Truthfulness: an agent may never say “booked” unless the execute tool returned a receipt, and offline output must be labelled simulated. Trajectory: for each scenario — breakdown, carrier outage, the rejection cases — we assert the expected handovers and tool calls. The offline suite runs in CI on every push; in live mode the same scenarios run as ADK eval sets with an LLM-judge rubric.
