Ghost Dispatcher

06

Left to right: the React control room talks to a FastAPI backend over REST and a server-sent event stream. The backend runs an ADK team — a Dispatcher plus seven specialists. Agents never touch the world directly: they call deterministic services that plan, validate and execute, with retry, circuit-breaker and fallback logic, and persist to SQLite. Those services reach the outside world: our logistics MCP server, the carrier API and Google Maps, Sheets, Calendar and Gmail. Offline mode swaps Gemini for a deterministic model double, so judges can reproduce every run without API keys.
