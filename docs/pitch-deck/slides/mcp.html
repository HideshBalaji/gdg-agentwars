Our logistics data lives behind an MCP server built on the official Python SDK, with eight tools, served over streamable HTTP with bearer auth. The Intake and Route & Risk agents discover those tools at runtime; write tools forward to the API so they stay validated and replay-safe. On the Google side: ADK for agents, Gemini Pro and Flash, Maps Routes for ETAs, and Sheets, Calendar and Gmail for the fleet board, dock slots and notifications. Every adapter has an offline twin that labels its output as simulated.
