Ghost Dispatcher

04

Every incident runs through the same seven-stage loop: detect, understand, re-plan, validate, act, notify, learn. Each stage has a specialist agent that owns it, shown in amber. The Watchdog sits across all of them. The same agents can handle other incident types — fridge failure, a customer who isn’t there to receive — the loop doesn’t change.
