The Critic turns a human rating into a typed preference: if we can save at least five thousand rupees by arriving at most ninety minutes later, still inside both deadlines, prefer the cheaper carrier. It’s scoped to the customer and cargo profile, it expires, and it only re-ranks plans that already passed every hard check. Free-text feedback is stored as data, never executed. The cost drop from 18,500 to 12,000 rupees on a comparable incident is reproduced by make demo on every CI run.
